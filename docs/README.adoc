= Documentation

This folder is an Antora documentation component for the Help repository.

== Structure

* `antora.yml` - Component descriptor defining name, version, and navigation
* `modules/` - Documentation modules (typically ROOT)
** `modules/ROOT/pages/` - AsciiDoc documentation pages
** `modules/ROOT/nav.adoc` - Navigation structure

== Antora Integration

This documentation is aggregated into the unified FoodTruckNerds documentation site via the playbook in the https://github.com/FoodTruckNerds/docs[docs repository].

Published site: https://docs.foodtrucknerdz.com/help/latest/

== Pages

* `modules/ROOT/pages/index.adoc` — component overview
* `modules/ROOT/pages/developing.adoc` — contributor setup and allow-list `.gitignore`
* `modules/ROOT/pages/changelog.adoc` — changelog index with detail pages under `changelog-details/`

NOTE: The Help repository also contains an Astro + Starlight documentation site for public-facing help at `help.foodtrucknerdz.com`. The Antora component here is aggregated into the org playbook in the `docs` repository.
