== About the project

This repository contains the customer-facing help documentation for FoodTruckNerdz.

=== Structure

* *Astro + Starlight* — Landing page at the site root (`help.foodtrucknerdz.com`) and documentation at `/docs`
* *Antora component* — `docs/` is published on link:https://docs.foodtrucknerdz.com/help/latest/[FTN Docs] via the `FoodTruckNerdz/docs` playbook

=== Documentation

* Public site: `help.foodtrucknerdz.com` (landing) and `help.foodtrucknerdz.com/docs` (Starlight)
* Org docs: contributor guide and changelog in the Antora component (`docs/modules/ROOT/pages/`)

== Getting started

[source,bash]
----
pnpm install
pnpm dev
pnpm build
----
